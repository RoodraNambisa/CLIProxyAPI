### Transport defect and bounded change

- Without a dedicated login proxy, login, OAuth refresh and Session refresh constructed `NewClient` with a zero transport timeout. The dependency's ordinary HTTP CONNECT dialer installs `time.Now().Add(0)` as a socket deadline, causing immediate failure.
- These three credential-acquisition paths now use the existing acquisition client and its tracked proxy dialer. Both refresh paths also close their owned active acquisition connections on return, as login already does.
- The existing acquisition context still bounds the complete flow. Business request transports, fingerprints, retry counts, lifecycle classifications and production settings are unchanged. No credential-wide scans or shared locks were added.
- Local proxy fixtures cover login, re-login, OAuth refresh, Session refresh, genuine CF responses and unknown HTML 403 responses. Transient refresh failures must remain retryable, preserve the previous token and never become `dead`.
- Cloudflare documents background JavaScript Detections as distinct from an interstitial challenge: <https://developers.cloudflare.com/cloudflare-challenges/challenge-types/javascript-detections/>. A normal page's JSD script is not sufficient challenge evidence.
