## 请求链路

| 阶段 | 输入 | 输出 | 证据 |
|---|---|---|---|
| SDK loader | `GET /backend-api/sentinel/sdk.js` | 固定版本 SDK URL | 2026-09-12 直连仍返回 `20260219f9f6` |
| SDK source | `GET /sentinel/20260219f9f6/sdk.js` | Sentinel SDK | SHA-256 仍为 `4f8ef8d5870894fd0101fc40ff45ea13c0f8e25c71c2ba28e5df5baf98babbb5` |
| requirements | `POST /backend-api/sentinel/chat-requirements/prepare` | `collector_dx`、`snapshot_dx` | 单凭证隔离实例真实图片请求复现 |

## 运行时补充

- 当前状态：已确认首个分歧并完成真实请求二跳验证
- 目标链路 / 函数：`BeginObserver` → collector → `SentinelObserver.Snapshot`
- 浏览器现象：collector 后 `window.__oai_so_owner` 为稳定可读的 36 字符 UUID 字符串

- 浏览器画像：使用凭证自身持久化 persona；不依赖操作者浏览器画像
- 注入时机：collector 执行期间
- 状态闭合信号：collector Promise 完成后、snapshot 开始前
- 状态载体：同一 Session Observer VM 的 `window` 页面状态
- 下一步：完成并发与全量回归验证
